## dissected_it_javascript
### JS for dissected.it website (physics based animated dimension reduction algorithm)

This is the JavaScript for the website [https://dissected.it](https://dissected.it). Im not very good at JS, but it might be interesting to see how the animated visualization of the word embeddings was realized. It uses some kind of *dimension reduction* method based on a simple physical model (mechanical: spring forces). As an algorithm it has not very good properties (PCA for instance is **far** better), but it allows to *animate* the search of the algorithm for a solution which is visually very attractive.
